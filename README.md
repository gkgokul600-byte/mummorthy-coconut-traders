# Mummorthy Coconut Traders

Website for Mummorthy Coconut Traders, built with React + Vite.

Features: product range, why-us, ordering steps, WhatsApp quote form, hand-drawn SVG coconut artwork and a coconut that falls down the page as you scroll.

## Run locally

```bash
npm install
npm run dev
```

## Edit business details

Update phone, WhatsApp number, email, address and hours in `src/config.js`.

## Deploy on Vercel

1. Go to https://vercel.com/new and import this GitHub repository.
2. Framework preset: **Vite** (auto-detected). Build command `npm run build`, output `dist`.
3. Click **Deploy**. Every push to `main` redeploys automatically.
